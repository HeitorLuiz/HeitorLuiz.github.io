<h2 align="center"> Descrição do projeto </h2>
<p>Um portfólio simples desenvolvido como projeto prático após a conclusão do curso "Git e GitHub do básico ao avançado", com o objetivo de colocar em prática os conhecimentos adquiridos e explorar o uso do GitHub Pages. O projeto apresenta algumas informações básicas sobre minha trajetória no ecossistema Salesforce, incluindo tecnologias, estatísticas de estudos no Trailhead, nuvens nas quais foco, além de links para contato, para meus perfis no Trailhead e para meu portfólio mais completo, criado no Experience Cloud da Salesforce. O projeto foi desenvolvido utilizando HTML5, CSS3, JavaScript e Bootstrap, com uma proposta simples, responsiva e uma identidade visual inspirada no Salesforce.</p>
